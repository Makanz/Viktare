# Bidra till Viktspåraren

Tack för att du är intresserad av att bidra till Viktspåraren! 🎉

## Hur kan jag bidra?

### Rapportera Buggar

Om du hittar en bugg, öppna gärna en [Issue](https://github.com/DITTANVÄNDARNAMN/viktspårare/issues) med:
- En tydlig beskrivning av problemet
- Steg för att återskapa buggen
- Vilken Python-version och operativsystem du använder
- Eventuella felmeddelanden

### Föreslå Nya Funktioner

Har du en idé för en ny funktion? Öppna en Issue och beskriv:
- Vad funktionen ska göra
- Varför den skulle vara användbar
- Eventuella exempel eller mockups

### Skicka in Kod

1. Forka projektet
2. Skapa en ny branch för din feature (`git checkout -b feature/MinNyaFeature`)
3. Gör dina ändringar
4. Testa att koden fungerar
5. Commit dina ändringar (`git commit -m 'Lägg till MinNyaFeature'`)
6. Push till branchen (`git push origin feature/MinNyaFeature`)
7. Öppna en Pull Request

### Kodstil

- Använd 4 mellanslag för indentering
- Följ PEP 8 när det är möjligt
- Kommentera komplex kod
- Svenska kommentarer är OK (projektet är på svenska)

### Testa Din Kod

Innan du skickar in en Pull Request, se till att:
- Koden startar utan fel
- Alla befintliga funktioner fungerar
- Din nya feature fungerar som förväntat

## Frågor?

Öppna gärna en Issue om du har några frågor!
